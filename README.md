# SHAM — hair-wash tracker source

Flutter-трекер последней отметки мытья головы и выбранного пользователем интервала.
Экран позволяет настроить заголовок, отметить текущую или выбранную дату и увидеть
рассчитанный статус следующей отметки. Android-исходники содержат домашний виджет
и мост для обновления/закрепления виджета.

## Данные

Заголовок, интервал и последняя дата хранятся локально через SharedPreferences.
Исходное значение последней даты — `null`; реальный журнал пользователя,
установленные приложения, резервные копии и device preferences не поставляются.
Облачная синхронизация и серверная часть отсутствуют.

## Flutter-проверки

Проект требует Dart 3.8.1+; исходная копия проверяется с Flutter 3.32.4 / Dart 3.8.1.
Используйте установленный совместимый SDK и выполняйте из корня проекта:

```sh
flutter pub get --enforce-lockfile
flutter analyze --no-pub
flutter test --no-pub --reporter expanded
```

Widget-тест задаёт пустые mock SharedPreferences до создания приложения и
проверяет основной экран. Он не загружает существующий дневник и не запускает
приложение на устройстве. Фактический результат публикационных проверок находится
в `PUBLICATION.md`, если этот файл добавлен издателем.

## Android source packaging

В копии сохранены Kotlin-код домашнего виджета, layouts, styles и manifest.
Вместо непроверенных launcher bitmap-иконок добавлена отдельная исходная vector
иконка с простым рисунком капли. Упаковка APK/AAB, установка, закрепление и
автоматическое обновление домашнего виджета на Android здесь не подтверждены.

Gradle wrapper JAR, launcher bitmap-пакеты, `local.properties`, SDK/Gradle caches,
ключи подписи и готовые APK/AAB исключены. Для сборки Android потребуется
восстановить wrapper из проверенной совместимой toolchain и настроить свои JDK/
Android SDK. Наличие Dart/widget-тестов не означает, что Android-пакет уже собран.

Это самостоятельная исходная заготовка трекера. Отдельная лицензия на собственный
код пока не выбрана; сторонние зависимости сохраняют свои условия распространения.
